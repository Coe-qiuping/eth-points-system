### B · 合约与测试（5.5h）

- [ ] `test/points.test.js` 10 条用例（清单见下）
- [ ] Gas 实测：`issue` / `transfer` / `approve` / `redeem` 四种交易的 `gasUsed`，整理成表
- [ ] **第 3 章** 合约实现与 MetaCoin 对比（权限三层 + 差异表，直接引用测试结果）
- [ ] **第 5 章** 测试与部署（测试截图 + 部署输出 + 地址表）

**10 条用例**：
1. `decimals() == 0`
2. 部署后 owner 自动在 `isIssuer` 白名单
3. 非 issuer 调用 `issue` → revert `NotIssuer`
4. `issue(to, 0)` → revert `ZeroAmount`
5. `batchIssue` 数组长度不等 → revert `LengthMismatch`
6. A → B 转账 200，双方余额正确
7. 非兑换合约调用 `consume` → revert `NotRedemptionStore`
8. `approve` + `redeem`：余额减少、库存 -1、`totalConsumed` 增加、订单 +1
9. 余额不足 / 库存为 0 / 已下架 → 各自对应错误
10. `pause()` 后 `issue` 与 `redeem` 均失败；`circulatingSupply == totalIssued - totalConsumed`
